## 2. 내 의뢰 (`/my-requests`, `src/components/my-requests/`, 계산 `src/lib/requests/`)

**구조**: 한 화면 + 상태 3단계(요청 받는 중 → 진행중 → 계약 완료) + 종료(취소·만료·거둬들임·다른 곳 계약·전원 해제).

**2026-10-27 섹션 정리 (대표님 시안, 모든 단계 같은 틀)**
- **현황판** (`RequestHero`): 흰 카드 하나 = 한 줄 제목(22px, 진행 중은 `부동산 n곳과 진행 중이에요`) → 칩(광고 n곳·방문 n건 · 가장 가까운 날짜·시각·새 소식 n, 0은 숨김. **점 알약 `StatusPill`, 색은 상태대로**: 광고 초록·방문 24시간 안 노랑/그보다 멀면 회색(`ownerTodo.heroVisit`)·새 소식 파랑. **누르면 그 섹션으로 스크롤**: 광고 → 진행 중인 부동산, 방문 → 우리 집 방문 설정, 새 소식 → 새 소식이 있는 카드) 또는 남은 시간 → 이름 동그라미 진행 표시(`common/StepCircles`, 요청 창과 공용) → `가장 먼저 확인할 일이 맨 위로 올라와요` → 구분선 아래 `나의 매칭 요청 · 단지 · 평형 거래` 줄 + 오른쪽 `펼치기`(펼치면 동·호수·희망가·제안 복비, `RequestSummaryDetail`). 받는 중엔 펼친 채 시작. 따로 있던 요청 카드는 없앰

  - **빨강 = 긴급 알림 상자** (공용 `common/UrgentAlert`, 2026-10-27 대표님 "급해 보여야 흐름이 돈다"): 연한 빨강 상자 + `지금 확인할 일이 n건 있어요` + `누르면 바로 확인할 수 있어요`(집주인은 잠금 규칙이 없어 잠금 문구 없음) + 할 일 목록(누르면 그 일) + 빨간 `지금 하기` 하나(맨 위 할 일)

**② 진행중**
- 확정한 곳만 사무소 정보 공개. 사무소 이름 → 상세 시트(지도 + 전화 `tel:` + 문자 `sms:`, 카카오톡 없음). 지도는 `/api/office-map`이 VWorld 정적 지도를 대신 받아 키를 숨기고 다산동 좌표만 허용(`officeMap.ts`)
- 광고: `광고 준비중 · 32시간 남음` + `기한 안에 안 올리면 매칭을 해제할 수 있어요` → 48시간 지나면 `[매칭 해제]`(한 곳만 빼기는 이 경우만). 올리면 `광고중 · n일째` + `내 아파트 광고 보기`(매물번호만으로 `fin.land.naver.com/articles/{번호}`, `naverListing.ts`)
- 방문 가능 시간(`showing.ts`): 방문 예약 목록 → 매주 방문 시간(요약 한 줄, `바꾸기`로 요일×오전/오후/저녁, 최소 1칸) → 안 되는 날(기간 최대 7일, 끝나면 자동으로 다시 열림). 전체 끄기 스위치 없음. 세입자 거주는 안내만(중개사가 세입자에게 직접 연락)
- 판매 상태: `● 판매 중` 스위치, 7일 보호 중엔 잠김 → 끄면 `잠시 멈추기`(광고만 내림, 다시 시작 시 48시간 기한 재시작) / `매물 거둬들이기`(종료) + 이유 칩
- `계약했어요` → 사무소 선택 또는 `다른 곳에서 계약했어요` → 나머지 광고 자동 내림. 중개사가 먼저 알리면 `○○가 계약을 알렸어요. 맞나요?`

**③ 계약 완료**: 중개사가 48시간 안에 계약일·잔금일 보고, 지나면 집주인 직접 입력 → `합의한 복비 {fee} 그대로 계약하셨나요?` 네/아니요(복비 약속 이행 기록 — 계약일·잔금일을 중개사가 직접 알린 거래만 1건, 집주인이 대신 입력하면 쌓이지 않음. `countsAsKeptPromise`) → 잔금 다음 날 별점 + 칩 후기(글 없음)

**종료**: 요청 0곳 만료면 `복비 조절하고 다시 요청`, 아니면 `같은 집 다시 요청` + 지난 의뢰 목록. 빈 화면은 한 번도 요청하지 않은 사람만.

**다시 요청 (A안)**: 시트 = 복비 ±10만·±1만 + 요청서 5줄(희망가·점유·입주·근저당·옵션) 각 `수정`. `수정` → localStorage `bokbi_resume_request`({단계, 복비, 요청서}) + `/analysis/{단지}?resume=1` → 분석 화면이 평형·거래 유형·층을 맞추고 모달을 그 단계부터 값이 채워진 채 연다 → `수정 완료 · 확인하기`로 5단계 바로. 본인 인증 재사용, 서약은 다시. 동·호수·소유주가 바뀌면 `처음부터 새로 요청`. (`requestDraft.ts`)

**블라인드 원칙 (대표님 강조)**: 매칭된 중개사끼리도 서로 모른다. 중개사 화면에서 다른 중개사가 잡은 방문은 "예약된 시간"으로만, 다른 곳 계약 시 나머지에는 "의뢰가 종료됐어요"만.

**목업·테스트**: `mock-requests.ts`("예시" 이름, 가짜 실적 없음 — 실적 숫자는 테스트 스위처 "실적 있는 예시"에서만), 화면 맨 아래 테스트 스위처 16가지(배포 전 제거). 계산 테스트 `src/lib/requests/__tests__/` 31개.
