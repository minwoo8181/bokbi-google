# 디자인 실험 킵 목록

레퍼런스 시안에서 **대표님이 직접 짚은 조각만** 모은다. 다음 레퍼런스로 넘어가도 킵 코드는 지우지 않고, 나중에 모아 조합해 완성한다.

- 킵 부품: `src/components/lab/keeps/` (테마와 무관하게 토큰만 써서 어느 테마에서도 쓸 수 있음)
- 킵 문구: `src/config/labContent.ts` → `LAB_CONTENT.keeps`
- 캡처: `docs/lab/keeps/` (대표님이 빨간 상자로 표시한 원본)
- 화면에서 찾기: 킵 부품 맨 바깥에 `data-keep="K번호"`

| 킵 | 조각 | 출처 레퍼런스 | 화면 | 부품 | 캡처 | 날짜 |
|---|---|---|---|---|---|---|
| K1 | 분석 머리 띠 + 근거 목록: 연파랑 띠 위 "적정 복비는 / {금액}이에요" 두 줄(금액만 파랑) + 기준 실거래 한 줄, 아래 최근 실거래·법정 상한·추천 할인·적정 복비 목록 | 삼쩜삼 종합소득세 리포트 ([wwit](https://wwit.design/2024/11/03/3o3/)) | 분석 맨 위 | `KeepFeeReportHero.tsx` (+ `ReportRow.tsx`) | [K1](keeps/K1-fee-report-hero.png) | 2026-10-30 |

## 조합할 때 주의
- K1·K2의 숫자는 모두 `AnalysisClient` 계산 그대로(법정 요율·추천 엔진). 부품은 받아서 그리기만 한다
- K2 비교 막대 노랑은 `--lab-compare`(삼쩜삼 테마 값). 다른 테마에서는 `--status-caution`으로 대신 칠해진다 — 조합 때 색을 정한다
- K3는 지금 홈에서 늘 첫 단계. 내 의뢰처럼 단계가 있는 화면에 `current`를 넘겨 다시 쓸 수 있다
