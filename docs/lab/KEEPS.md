## 바뀐 기록
- 2026-10-30 K1·K2: 대표님이 다시 짚음(캡처 `-v2`). K4~K7 추가. 고른 것 전체 정리(값·문구·코드)는 대표님이 지정한 `design-lab-picks.md`
- 2026-10-30 K1: 맥락 줄(`contextLine`)이 글자 대신 요소도 받게 했다 — 삼쩜삼 분석은 이 자리에 단지 이름 + 조건 칩(평형·층·거래 ⌄ → "내 집 조건" 시트)을 넣는다. 글자를 넘기면 예전 모양 그대로
- 2026-10-30 K1: 동그라미 안 영수증 아이콘 삭제(taste 아이콘 칩 금지), 목록 끝 "적정 복비" 줄 삭제(위 금액과 같은 사실 — 같은 숫자는 한 곳에만)
- 2026-10-30 K1: 금액 26px → 40px (스킬 점검 — 답이 되는 금액이 화면에서 가장 커야 하는데 K2 제목과 같은 26px이었다)

## 조합할 때 주의
- K1·K2의 숫자는 모두 `AnalysisClient` 계산 그대로(법정 요율·추천 엔진). 부품은 받아서 그리기만 한다
- K2 비교 막대 노랑은 `--lab-compare`(삼쩜삼 테마 값). 다른 테마에서는 `--status-caution`으로 대신 칠해진다 — 조합 때 색을 정한다
- K3는 지금 홈에서 늘 첫 단계. 내 의뢰처럼 단계가 있는 화면에 `current`를 넘겨 다시 쓸 수 있다
